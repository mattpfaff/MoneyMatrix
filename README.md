# MoneyMatrix
Recreating a flash game I used to play 20+ years ago in Odin
Take turns collecting a money value from the grid, but options for your opponent depend on what you pick. 
Can you collect the most money while denying the best values to your opponent.

Using Karl2d for now from here:
https://github.com/karl-zylinski/karl2d
Download the repo as a zip and extract into k2 folder in same location as moneymatrix.odin

Follow steps here to get Odin compiling and running:
https://odin-lang.org/docs/install/

Game is fully playable but rough.
